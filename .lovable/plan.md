

# 거래명세서 자동 생성 프로그램 구현 계획

## Phase 1: 기반 설정
1. **디자인 토큰 적용** — 상세서의 Color, Typography, Spacing, Radius, Shadow, Motion 토큰을 CSS 변수와 Tailwind 설정에 반영 (Light 테마 전용, 폰트: Segoe UI/Malgun Gothic)
2. **App Shell 구축** — 헤더(56px) + 좌측 사이드바(264px/접힘 72px) + 콘텐츠 영역 + 우측 인스펙터(360px, 와이드 모드) 공통 레이아웃
3. **반응형 브레이크포인트** — bp_compact(≤1200px), bp_regular(1201~1600px), bp_wide(≥1601px) 적용
4. **전역 검색(Ctrl+K)** — cmdk 기반 커맨드 팔레트 (업체/품목/로그 검색)

## Phase 2: Supabase 백엔드
5. **Supabase Cloud 연동** — 데이터베이스 테이블 생성:
   - `vendors` (업체 관리)
   - `unit_prices` (단가)
   - `mapping_rules` (매핑 규칙)
   - `processing_logs` (처리 로그)
   - `settings` (설정)
6. **RLS 정책 설정** — 인증된 사용자만 접근 가능하도록 보안 설정

## Phase 3: 6개 메뉴 화면 구현

### 3-1. 일괄 처리 (대시보드, 기본 진입)
- 상단 필터바(56px, sticky): 날짜 선택 + 입력폴더 + 출력폴더 + "일괄 처리 시작" (Button.lg)
- 진행률 바(8px) + 요약 카드(성공/경고/실패 건수, 금액 합계)
- 결과 테이블(7열): 상태/업체/파일명/문서번호/금액/저장경로/결과
- 행 액션: 미리보기/오류보기/재시도
- 실패 시 나머지 계속 진행, "실패 항목만 재시도" 버튼

### 3-2. 업체 관리 (리스트+상세)
- 좌측: 검색 + 업체 테이블 (200개 이상 대응)
- 우측: Drawer(420px)로 상세 편집
- 탭 구성: 기본/단가/매핑/생성규칙/예외키워드/OCR
- 인라인 유효성 검증 (업체명/발행번호/저장경로 필수)

### 3-3. 매핑 마법사 (Wizard)
- 좌측 단계 목록(240px) + 우측 폼 영역
- 단계: ① 샘플 업로드(Drag&Drop) → ② 필드 매핑 테이블 → ③ 미리보기(Modal.lg) → ④ 저장
- 오류 1개라도 있으면 저장 불가 (블로킹 검증)

### 3-4. 단가·규칙
- 품목별 단가 관리 테이블 (CRUD)
- 규칙 편집: 텍스트 영역 + 조건부 로직 UI

### 3-5. 로그·리포트
- 상단: 날짜 범위 선택 + 엑셀 다운로드 버튼
- 테이블: 실행ID/일시/성공/실패/금액합계
- Drawer로 상세 확인 (실패 사유/파일 리스트/재시도)

### 3-6. 설정
- 저장경로 입력 + 찾아보기
- OCR API 키 (마스킹 + 테스트 버튼)
- 모션 최소화 토글 (접근성)
- 초기화 버튼 (확인 모달 필수)

## Phase 4: 공통 컴포넌트 (상세서 규격 준수)
- **Button**: Primary/Secondary/Danger, 3가지 크기(sm/md/lg), 7가지 상태
- **Input/Textarea**: 상태별 보더/포커스 링 규격 적용
- **Card**: radius 14px, error 시 좌측 4px 빨간 보더
- **Modal**: sm(480px)/md(640px)/lg(840px), 포커스 트랩
- **Drawer**: 우측 420px, bp_compact에서 전체 모달 대체
- **Toast**: 우상단 고정, 오류는 자동 닫힘 금지
- **Table**: sticky 헤더, 스트라이프, 행 hover/선택, 빈 상태 카드

## Phase 5: 접근성 & 마무리
- 포커스 링(#93C5FD, 2px) 모든 인터랙티브 요소
- 키보드 네비게이션 (Tab/Shift+Tab/Esc)
- 최소 클릭 영역 32×32px
- 오류는 색+텍스트 동시 제공
